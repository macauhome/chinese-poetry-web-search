詩經
====

中國最早詩歌總集, 《詩經》，是中國古代詩歌開端，最早的一部詩歌總集，收集了西周初年至春秋中葉（前11世紀至前6世紀）的詩歌，共311篇，其中6篇爲笙詩，即只有標題，沒有內容，稱爲笙詩六篇（南陔、白華、華黍、由康、崇伍、由儀），反映了周初至周晚期約五百年間的社會面貌。 來自百科
