# 曹操詩集

曹操喜歡用詩歌、散文來抒發自己政治抱負，反映民生疾苦，是魏晉文學的代表人物，其文學成就，
主要表當今詩歌上，散文也很有特點。曹操的詩歌，今存20多篇，全部是樂府詩體。
內容大體上可分三類。一類是關涉時事的，一類是以表述理想爲主的，一類是遊仙詩。

## 說明

本庫收錄操作詩詞26首，部分詩詞中標註了全網版本的疑字。

收錄語言爲簡體中文。
