全宋詞
-----

《全宋詞》是中國近百年來最重要的古籍整理成果之一。宋詞和唐詩均爲中國古典詩的藝術高峯。清代所編《全唐詩》是家喻戶曉籍，現又新編出《全宋詞》，堪稱中國文學的雙璧。全書共五冊，薈萃宋代三百年間的詞作。來自[百科](https://baike.baidu.com/item/%E5%85%A8%E5%AE%8B%E8%AF%8D)

## 說明

簡體中文分發。

## 已知問題

1. 尚存在一些繁體字，由於找不到對應的簡化字，或是不能確定是否應當簡化，仍保留在詞中。
2. 部分異體字、通用字，不及一一對照原本考證用法，只得保留。例如：`搵`與`搵`,`酴醿`與`酴醾`，`溟濛`與`溟濛`，`鴻濛`與`鴻蒙`等。
