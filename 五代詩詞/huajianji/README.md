花間集
=====

《花間集》是中國五代十國時期編纂的一部詞集，也是文學史上的第一部文人詞選集，由後蜀人趙崇祚編輯。本書收錄了溫庭筠、韋莊等18位花間詞派詩人的經典作品，集中而典型地反映了早期詞史上文人詞創作的主體取向、審美情趣、體貌風格和藝術成就。


## 注意

本目錄數據保存了所有的花間集數據詩詞，由於五代十國朝代的原因， 可能與全唐詩和全宋詞的詩詞重複。  這是正常的。
