南唐二主詞
=========

《南唐二主詞》，系南唐中主李璟、後主李煜撰。約成書於南宋，後世續有輯補，又有後人編寫了各種版本

**注意：** 可能和全唐詩和全宋詞內容有重複詩詞發生， 這是正常的。
