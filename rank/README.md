詩詞搜索結果
-----

根據該[關於詩詞的知名度](https://github.com/chinese-poetry/chinese-poetry/issues/115)整理的數據，以“作者＋作品名”做爲搜索關鍵字，通過搜索引擎搜索，並把搜索結果數量做爲排行的一個維度製作而成，目前收集了“百度、必應、360搜索和谷歌”等`4`個引擎的數據，其中必應又分爲中國版搜索結果和國際版搜索結果

一般來講，搜索結果越多，表示該詩詞越知名。

## 說明

該目錄下收集了`ci`和`json`兩個文件夾下的詩詞搜索數據，且該文件夾下的文件與`ci`和`json`中的文件一一對應，比如`./ci/ci.song.rang.8000.json`對應`../ci/ci.song.8000.json`。

不但文件一一對應，文件中的內容也是一一對應的，即`./ci/ci.song.rang.8000.json`中數組中的第`n`條和`../ci/ci.song.8000.json`數組中的第`n`條對應

#### 爲什麼沒有把該結果和詩詞數據放在一起？
爲了保持詩詞數據的純潔，並非所有數據都適合塞進去。對於這種非所有人需要的數據，通過一一對應關係，可以很方便的給原詩詞擴展數據，同時也保證了原詩詞的純潔度。所以當需要對詩詞根據知名度排序的需求時，可以把該數據附加到原有詩詞數據上即可。


## 數據形式

每個 JSON 文件1000條記錄. 爲了舉例， 刪除了餘下999條.

```js
[
  {
    "author": "石孝友",
    "rhythmic": "玉樓春",
    "baidu": 77500, //百度搜索結果條數
    "so360": 1060,//360搜索結果條數
    "google": 991000,//谷歌搜索結果條數
    "bing": 20//必應搜索結果條數
  }
]
```

搜索引擎的結果數據僅供參考，不同時間搜出來的數據會有一些出入
