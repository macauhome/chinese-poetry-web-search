論語
====

中國儒家經典,《論語》是孔子及其弟子的語錄結集，由孔子弟子及再傳弟子編寫而成，至戰國前期成書。全書共20篇492章，以語錄體爲主，敘事體爲輔，主要記錄孔子及其弟子的言行，較爲集中地體現了孔子的政治主張、倫理思想、道德觀念及教育原則等。此書是儒家學派的經典著作之一，與《大學》《中庸》《孟子》並稱“四書”，再加上《詩經》《尚書》《禮記》《周易》《春秋》，總稱“四書五經”。 來自百科
