詩詞平仄
-----

## 說明

該目錄下收集了`json`文件夾下的詩詞平仄數據，且該文件夾下的文件與`json`中的文件一一對應，比如`./json/poet.song.rang.8000.json`對應`../json/poet.song.8000.json`。

不但文件一一對應，文件中的內容也是一一對應的，即`./json/poet.song.rang.8000.json`中數組中的第`n`條和`../json/poet.song.8000.json`數組中的第`n`條對應

#### 爲什麼沒有把該結果和詩詞數據放在一起？
爲了保持詩詞數據的純潔，並非所有數據都適合塞進去。對於這種非所有人需要的數據，通過一一對應關係，可以很方便的給原詩詞擴展數據，同時也保證了原詩詞的純潔度。所以當需要對詩詞根據知名度排序的需求時，可以把該數據附加到原有詩詞數據上即可。


## 數據形式

每個 JSON 文件1000條記錄. 爲了舉例， 刪除了餘下999條.

```js
[
  {
    "strains": [
        "○仄仄，仄仄仄仄。",
        "？仄平仄仄仄仄仄仄仄平平○？？？？？？？。"
    ],
    "id": "xx-yy-zz"
  }
]
```
